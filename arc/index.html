Biometric Voting System Architectures

Diagram 1: Edge Hardware Layer

R307 Fingerprint Sensor (UART @ 57600 Baud)
Push Button Interface (GPIO Pins: 13, 14, 25, 26)
ESP32 Microcontroller Local Match Verification & Duplicate Flagging
16x2 I2C LCD Display Voter Status Feedback
⬇ Outbound: HTTP POST over Local Wi-Fi ⬇

Diagram 2: Node.js Middleware Layer

⬆ Inbound: JSON Payload (voterID, party) ⬆
Express API Server Receives Edge Data on Port 3000
Identity Anonymization Engine Converts voterID into SHA-256 Crypto Hash
Pre-Flight Fraud Validation Reads state from Blockchain to prevent gas waste
Ethers.js Web3 Bridge ECDSA Transaction Signing using Private Key
⬇ Outbound: JSON-RPC Web3 Request ⬇
